# Pixel Perfect Web

Rol: Actúa como un desarrollador Frontend experto en React y Tailwind CSS.

Tarea: Construye la página web basándote exactamente en la imagen adjunta que diseñé en Canva.

Detalles de diseño y estructura:

Fidelidad visual: Respeta la distribución de elementos, los colores principales, las tipografías y el espaciado tal como se ven en la imagen.

Diseño Adaptable (Responsive): Asegúrate de que la página se adapte correctamente a pantallas de móvil, tablet y escritorio.

Componentes interactivos:

Convierte los botones en elementos interactivos con efectos sutiles al pasar el cursor (hover effects).

El botón Cotizar por whatsapp conviertelos para que envíen whatsapp a este numero 812 594 76 79

y en los botones Solicitar cotización has que envíen al formulario que está al inicio, el que tiene por nombre "Solicita tu cotización" y que las respuestas de ese formulario lleguen directamente a este correo contacto@frioequipos.com

Tecnologías: Utiliza componentes limpios, reutilizables y con estilo moderno (Tailwind CSS).
